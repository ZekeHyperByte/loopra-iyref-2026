# LOOPRA: Integrated Bio-Energy Supply Chain Protocol

Digitalizing Indonesia's organic waste supply chain for sustainable bio-fuel production. This monorepo contains two separate projects:

- **[loopra_apk](./loopra_apk)** — Flutter mobile app (Hackathon MVP) for waste producers (sellers), operators, and drivers. Features AI waste classification, e-wallet, collection point maps, QR payments, and carbon tracking.
- **[loopra_website](./loopra_website)** — React/TypeScript web dashboard (Enterprise Portal & Admin Command Center). Features inventory forecasting, geospatial hub network maps, fleet control, hub telemetry, digital carbon ledger, and ESG reporting.
